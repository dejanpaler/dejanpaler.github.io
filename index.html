Consulting and development

Since 2005 I have worked with clients in domains such as financial services, payments, regulated gaming and search engine optimization, building new Java systems and modernizing the ones they already run in production. On a new system I start with the architecture: documents, decision records and proofs of concept that the team uses to choose its technologies. Then I build the backend services, the front ends — with React, Angular, JSF or plain JavaScript — and the integrations with the systems around them. On a system already in production I move its functionality from the older platform to the current one, piece by piece.

The work does not end at release. I analyze incidents to their root cause, fix performance problems, and add observability so the next problem is found sooner. Around the team I set up code reviews, test automation and continuous delivery, and I train and mentor developers. Spec-driven and AI-assisted development are part of how I work every day.

I work on project delivery or on time and materials, remote from Slovenia.
